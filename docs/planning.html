05

High-level ERD

Every view reads the same tasks table. A Kanban column is a status, a Table section is a group, and Timeline and Calendar read the task's start and due dates.

erDiagram

  BOARDS ||--o{ TASKS : contains
  STATUSES ||--o{ TASKS : "state of"

RuleWhat it protects
start ≤ dueTimeline bars always run forward; checked on the server.
same boardA task's status, group and labels must belong to its own board.
is_doneMoving into a done status stamps completed_at; moving out clears it.
≥ 1 status, ≥ 1 groupDeleting one moves its tasks to a replacement you choose.
soft delete usersRemoved people keep their name on old comments; their tasks become unassigned.
archive firstA board must be archived before the owner can delete it.
